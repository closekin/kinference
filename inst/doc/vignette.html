Each call:

  • reads in the data from a DArT count csv file (as specified)
  • determines how many polyploid loci each fish has, and gets rid those with too many(set by an argument to the load_whopper function)
  • determines the genotypes based on the counts for every fish/loci to the 6-way level (e.g. AA/BB/AB/AO/BO/OO); it does so based on criteria/thresholds that were determined previously for each of the loci, and which are stored in the attributes of an object called “g0”
  • the first call to load_whopper needs passed the object “g0”, then each consecutive call gets passed the object created from the previous call and appends the new genotype data to it.
